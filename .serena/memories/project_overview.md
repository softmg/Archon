Archon is a remote agentic coding platform that lets users control AI coding assistants from Slack, Telegram, GitHub, Discord, CLI, and Web. It is a Bun + TypeScript monorepo with packages for adapters, server, core orchestration, workflows, git/isolation, and a React web UI. The architecture emphasizes simple platform adapters implementing IPlatformAdapter, strict typing, Zod schemas for API/workflow types, and minimal speculative abstraction.
