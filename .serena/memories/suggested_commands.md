Core development commands: `bun run dev`, `bun run dev:server`, `bun run dev:web`. Validation commands: `bun run test`, `bun run type-check`, `bun run lint`, `bun run format:check`, `bun run validate`. Important testing note: do not run `bun test` from repo root; use `bun run test` for per-package isolation. Useful targeted commands: `bun --filter @archon/adapters test`, `bun --filter @archon/core test`, `bun test <file>`. CLI entrypoints: `bun run cli workflow list`, `bun run cli workflow run <name>`, `bun run cli serve`.
