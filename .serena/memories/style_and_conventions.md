Prefer simple explicit control flow (KISS/YAGNI), fail fast on unsupported states, and avoid speculative abstractions. New/modified API routes use registerOpenApiRoute(createRoute(...)); Zod schemas use camelCase names and z.infer<typeof schema>. Prefer editing existing files, minimize comments, and keep platform adapters/auth logic encapsulated inside adapter modules.
